## What I Build

### 🧭 Autonomous Mobile Robots

Working with ROS 2-based mobile robots for:

- SLAM and mapping
- Localization
- Nav2 autonomous navigation
- Costmaps and obstacle avoidance
- Waypoint navigation
- Sensor integration
- Embedded motor control

### 🦾 Robotic Manipulation

Building and experimenting with robotic arms involving:

- Forward & inverse kinematics
- Motion planning
- MoveIt 2
- Trajectory execution
- ROS 2 control
- Computer-vision-guided manipulation

### 🚁 UAV Autonomy

Exploring autonomous UAV workflows using:

- PX4
- ROS 2
- Offboard control
- Simulation
- Navigation and perception

### 👁️ Robot Perception

Working with computer vision for robots using:

- OpenCV
- ArUco markers
- Object detection
- Face / user recognition
- Pose estimation
- RGB-D perception

### 🔌 Embedded Robotics

Building the hardware layer behind autonomous systems using:

- Raspberry Pi
- ESP32
- STM32
- Arduino
- Sensors and actuators
- UART / I²C / SPI
- Motor drivers
- Wireless communication
